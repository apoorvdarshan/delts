[ 01 / Capabilities ]

Built around
the timer

Delts treats the red start button as the source of truth. Add workouts, start the timer, log the work, and keep the rest quiet.

01

Daily workout board

Build today from the exercise library, saved workouts, or copied days. Cards show sets, reps, RPE, and muscle/equipment context at a glance.

HOME
02

Workout timer

The main red timer starts and ends the workout, drives session timing, and supports a focused Live Activity timer on iPhone.

TIMER
03

Set, rep & RPE logging

Log reps and effort only while the workout is active, with support for strength RPE and CR10-style effort tracking.

LOG
04

Exercise library

Browse exercises by target muscles, equipment, level, and split. Detail pages keep the image pinned while instructions scroll.

LIBRARY
05

Progress charts

Track weight and body fat across week, month, 3M, 6M, 1Y, and all-time, with visible grid lines, averages, net change, and goals.

PROGRESS
06

Apple Health sync

Optional HealthKit access can import and save body weight and body fat logs when you grant permission.

HEALTH
07

Body composition pickers

Choose exact body fat numbers or visual ranges, with separate preferences for current and goal body fat.

BODY
08

Personalized setup

Set height, weight, training goal, target muscles, issues, frequency, duration range, split, equipment, and optional 1RM anchors.

PROFILE
09

Custom themes & icons

Switch between Lime, Cyan, Pink, Amber, and Violet. The app tint and Home Screen icon change from one setting.

01

Start the session

The red button records start and end time. Editing set data is tied to an active timer, so planned workouts stay separate from performed work.

02

Log what you did

Add sets, reps, and RPE inline while the timer runs. The board shows live totals as the session builds.

03

Review the trend

Weight and body fat charts use a visible grid, four x-axis dates per range, and year labels when long ranges cross years.

04

Make it yours

Theme color and app icon stay matched, with real icon previews in Settings. Copy a previous day to start a session fast.
