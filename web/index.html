What Delts does

A gym app built around the session timer.

Delts treats the red start button as the workout source of truth. Add workouts, start the timer, log the work, and keep the rest quiet.

01

Daily workout board

Build today from the exercise library, saved workouts, or copied days. Cards show sets, reps, RPE, and the muscle/equipment context at a glance.

02

Workout timer

The main red timer starts and ends the workout, drives session timing, and supports a focused Live Activity timer on iPhone.

03

Set, rep, and RPE logging

Log reps and effort only while the workout is active, with support for strength RPE and CR10-style effort tracking.

04

Exercise library

Browse exercises by target muscles, equipment, level, and split. Detail pages keep the exercise image visible while instructions scroll.

05

Progress charts

Track weight and body fat with weekly, monthly, 3M, 6M, 1Y, and all-time ranges, visible grid lines, averages, net change, and goals.

06

Apple Health sync

Optional HealthKit access can import and save body weight and body fat logs when the user grants permission.

07

Body composition pickers

Choose exact body fat numbers or visual ranges, with separate preferences for current and goal body fat.

08

Personalized preferences

Set height, weight, training goal, target muscles, issues, frequency, duration range, split, equipment, and optional 1RM anchors.

09

Custom themes and icons

Switch between Lime, Cyan, Pink, Amber, and Violet. The app tint and Home Screen icon change from the same setting.

The flow

Start, train, log, review.

The homepage keeps workout setup visible, the detail view keeps instructions and exercise images close, and progress keeps the long-term signal readable.

Focused workout state

Editing set data is tied to an active timer. That keeps planned workouts separate from performed work.

Readable progress

Weight and body fat charts use a visible grid, exact four x-axis dates per range, and year labels when long ranges cross years.

Theme-linked identity

Theme color and app icon stay matched, with real icon previews in Settings.

Privacy and control

No account required. Health access is optional.

Delts is designed around local workout planning and logging. Apple Health access is permission-based and can be turned off by the user.
